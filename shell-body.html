Sincronización entre PCs (GitHub)

Comparte maestro de clientes, citas, topes SKU y código SKU entre varias computadoras. Repo: luisglazala/rutalog-datos

sin configurar

Crea un token en GitHub → Settings → Developer settings → Personal access tokens (permiso repo o solo este repositorio). Se guarda solo en este navegador.

Última sync: —

Guardado automático en GitHub (catálogos) (con token): cualquier cambio de usuarios, maestro de clientes, citas, topes SKU o código SKU (edición o importación Excel) se sube solo ~1–2 segundos después. También hay respaldo automática tras editar y cada minuto. En otra PC: mismo token → Actualizar → mismos datos y login.
